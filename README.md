Restaurant Management System

A console-based Restaurant Management System developed in C++ using Object-Oriented Programming concepts. This project helps manage restaurant operations such as ingredients, employees, orders, menu handling, billing, and customer management.

Features
Management Side
Admin authentication system
Add ingredients
Use ingredients
Restock ingredients
Display available ingredients
Employee check-in/check-out
View employee records
Customer Side
Display pizza menu
Place orders
Generate bills
Store pending and completed orders
