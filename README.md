# Restaurant Management System

A console-based Restaurant Management System developed in C++ using Object-Oriented Programming (OOP) concepts. The project simulates restaurant operations including order management, inventory handling, employee tracking, billing, and customer services.

---

## Features

### Management Module
- Ingredient inventory management
- Add, restock, and use ingredients
- Employee check-in and check-out system
- Authentication-based manager access
- Employee records management using file handling

### Customer Module
- Display restaurant menu
- Place customer orders
- Generate bills
- Support for dine-in, takeaway, and delivery customers

### Order Management
- Pending order tracking
- Completed order tracking
- File handling for order storage

---

- Classes & Objects

- File Handling
